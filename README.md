# LibraryWeb

## Опис проєкту 
Веб-застосунок **"Автоматизація бізнес-процесів приватної бібліотеки"**, створений у рамках дисципліни **Об'єктно-орієнтоване програмування**.

Проєкт автоматизує ключові бізнес-процеси бібліотеки:
* облік книг та користувачів,
* управління позиками, резерваціями та поверненнями,
* формування звітів та статистики,
* реалізація повнофункціонального **CRUD**-застосунку з дотриманням принципів **ACID**.

---

## Використані технології
* **Backend:** C#, .NET Core, ADO.NET
* **Шаблон:** MVC
* **База даних:** SQL Server / LocalDB
* **Frontend:** Razor Pages / MVC, CSS для стилізації інтерфейсу 
* **Інструменти:** Visual Studio, Git

---

## Основні функції
* Перегляд книг та користувачів
* **CRUD** операції для книг та користувачів
* Облік позик, повернень та резервацій
* Пошук книг за назвою або автором
* Формування звітів про стан бібліотеки
* Дружній інтерфейс користувача

## Запуск проєкту

1.  Клонувати репозиторій:

    ```bash
    git clone [https://github.com/dariavysot/LibraryWeb.git](https://github.com/dariavysot/LibraryWeb.git)
    cd LibraryWeb
    ```

2.  Відкрити проект у **Visual Studio**.

3.  Переконатися, що рядок підключення у `appsettings.json` налаштований (для LocalDB за замовчуванням).

4.  Запустити проєкт (**F5** або `dotnet run`).
