# Завдання до проєкту: "Автоматизація бізнес-процесів приватної бібліотеки"

**Дисципліна:** Об'єктно-орієнтоване програмування  
**Тип проєкту:** Web-застосунок (ADO.NET Core, MVC)

---

## 1. Мета проєкту
Автоматизація основних бізнес-процесів приватної бібліотеки:
- облік книг та користувачів;  
- управління позиками, резервацыями та поверненнями книг;  
- формування звітів та статистики;  
- реалізація повнофункціонального CRUD-застосунку з дотриманням принципів ACID.

---

## 2. Етапи роботи

1. **Побудова UML-моделі проєкту**
   - Структурні діаграми (класи, атрибути, зв'язки)  
   - Діаграми поведінки: діаграми діяльності, станів, прецедентів  

2. **Розробка застосунку**
   - Створення проекту на основі шаблону MVC  
   - Налаштування локальної бази даних (LocalDB або SQLite)  
   - Використання ADO.NET для доступу до бази даних  
   - Використання LINQ для роботи з колекціями даних  

3. **Розробка інтерфейсу**
   - Графічний інтерфейс користувача з об’єктно-орієнтованим підходом  
   - CRUD-операції: створення, читання, оновлення, видалення даних  

4. **Перевірка функціоналу**
   - Забезпечення принципів ACID  
   - Тестування повноти функціоналу  

---

## 3. Результат
- Повноцінний веб-застосунок бібліотеки  
- UML-діаграми, що описують структуру та поведінку системи  
- Локальна база даних з можливістю CRUD-операцій  
- Зручний інтерфейс користувача та звіти по бібліотеці
